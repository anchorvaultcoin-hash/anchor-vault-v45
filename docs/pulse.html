Как работает защита

Операции с сейфом подписываются отдельными ключами (основной и резервный), а не приватником вашего кошелька. Даже если злоумышленник украдёт ключ кошелька — он не получит доступа к средствам.

Операции

Операции с сейфом подписываются ключом сейфа. Сначала загрузите сейф во вкладке «Мой сейф» — оттуда подтянутся номер и счётчик.

📤 Простой перевод токенов

Обычный перевод ERC-20 со своего кошелька. Без сейфа, без подписи ключом — обычная транзакция кошелька.

A Вывод средств

Вывод токенов из сейфа на адрес. Подписывает основной ключ.

B Передача сейфа

Передать весь сейф другому владельцу с новыми ключами. Подписывает основной ключ.

C Досрочное закрытие

Закрыть сейф досрочно. Комиссия сервиса 5%. Подписывает резервный ключ. Средства идут владельцу.

D Эвакуация на резервный адрес

Вывод на заранее зафиксированный резервный адрес. Комиссия сервиса 10%. Подписывает резервный ключ.

E Аварийный вывод на любой адрес

Вывод на произвольный адрес. Комиссия сервиса 15%. Подписывает резервный ключ.

F Смена ключей сейфа

Заменить оба ключа сейфа. Подписывает резервный ключ.

G Изменить задержку

Задержка вывода в часах (зависит от уровня: SAFE 0, VAULT до 72, FORTRESS до 168). Основной ключ.

H Добровольная блокировка

Заблокировать вывод до даты (нельзя отменить досрочно). Основной ключ.

🆘 Сверхсрочный вывод (комиссия сервиса 20%, без подписи)

Мгновенный вывод средств на ваш резервный адрес. Комиссия сервиса 20%. Подпись не нужна, но вызвать может только владелец сейфа. Используйте только если потеряны оба ключа.

Панель Creator

Вывод из стратегического резерва.

Двухэтапная: сначала вы инициируете, затем новый владелец принимает.

F Замена Guardian

G Снять паузу контракта

Только Creator может вернуть контракт в активный режим после паузы.

Панель Guardian

🔒 Доступ только для Guardian

Подключитесь адресом Guardian, чтобы получить доступ.

Запрос ставится в очередь. Выполнить можно через 2 дня. Используйте при подозрении на атаку.

Мгновенная остановка контракта без задержки. Используйте при активной атаке — снять паузу сможет только Creator.

Журнал

Открыть новый сейф

⚠️ Важно — прочитайте перед открытием
  • Резервный адрес задаётся ОДИН РАЗ и его нельзя поменять мгновенно (только через 7-дневную процедуру). Указывайте адрес, к которому у вас точно есть доступ.
  • Резервный адрес НЕ может совпадать с адресом вашего кошелька — это и есть защита: при краже кошелька деньги уйдут на резервный адрес, а не вору.
  • Основной и резервный ключи — это ОТДЕЛЬНЫЕ адреса, не ваш кошелёк. Не теряйте их: восстановление возможно только через резервный адрес.
  • При открытии берётся комиссия сервиса 0.2%.
🟢 Как это работает (для новичков) — нажмите, чтобы развернуть

Сейчас вы вошли в пульт своим основным кошельком (MetaMask, Rabby и т.д.). Этот кошелёк НЕ управляет сейфом. Вам нужны три отдельных адреса-ключа.

Шаги:

  1. Откройте свой кошелёк (например MetaMask) в браузере.
  2. Нажмите на иконку аккаунта → «Добавить аккаунт» / «Create Account».
  3. Создайте так 2 новых адреса — это будут Основной ключ и Резервный ключ.
  4. Для Резервного адреса (куда эвакуировать) — заведите ОТДЕЛЬНЫЙ кошелёк: другой браузерный профиль, другое устройство или аппаратный кошелёк (Ledger/Trezor).
⚠️ Самое важное: Резервный адрес должен быть в ДРУГОМ кошельке с ДРУГОЙ seed-фразой. Если все адреса из одной seed-фразы — при её краже потеряете всё сразу, и защита не сработает.

После открытия сейфа сохраните seed-фразы всех кошельков в надёжном месте (бумага, не скриншот).

Популярные кошельки: MetaMask · Rabby · OKX Wallet · Trust Wallet · Coinbase Wallet · Ledger · Trezor
